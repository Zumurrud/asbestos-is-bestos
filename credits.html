Credits &c.

This site is based on the Rhodes Island Tetralingual Voice Archive by PseudoMon, built with SvelteKit and FontAwesome, and hosted on Github Pages.

The images are provided by FexliR's Arknights Resource repo. Some of the audio data (for replaced voice actors) comes from PseudoMon. I extracted all current audio from the game files, using UnityPy and python-fsb5. Audio data is available here.

You might also be interested in the Arknights Global Webcomics website, which PseudoMon made to more easily read the official global release of the comics.

More shout-outs:
